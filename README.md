# KimiaFaravar Warehouse

سامانه مدیریت انبار کیمیا فراور با ASP.NET Core MVC و رابط فارسی راست‌به‌چپ.

## امکانات فعلی

- ورود کاربران و کنترل دسترسی مبتنی بر نقش
- مدیریت گروه منابع و خصوصیات
- ثبت و مشاهده ورود و خروج کالا
- داشبورد و گزارش موجودی
- امکان انتخاب محل ذخیره‌سازی بین SQL Server و فایل‌های JSON

## اجرای پروژه

پیش‌نیاز: .NET SDK 10

```powershell
dotnet restore KimiaFaravar.Inventory.slnx
dotnet run --project src/KimiaFaravar.Web
```

سپس آدرسی را که در خروجی ترمینال نمایش داده می‌شود در مرورگر باز کنید.

## حالت JSON برای توسعه

در محیط Development، برنامه می‌تواند بدون SQL Server و با فایل‌های JSON اجرا شود. تنظیمات محل ذخیره‌سازی در فایل‌های `appsettings` پروژه وب قرار دارد. اطلاعات عملیاتی داخل `App_Data` محلی است و در Git نگهداری نمی‌شود.

حساب آزمایشی توسعه:

- نام کاربری: `admin`
- رمز عبور: `Demo@12345`

این حساب فقط برای اجرای محلی است و نباید در محیط عملیاتی استفاده شود.
