# Kimia Faravar visual system

UI UX Pro Max searches: inventory operations dashboard modern (design-system), dashboard minimal (style, full RTL).

Direction: restrained flat operational dashboard, Persian RTL. Use the supplied purple logo unchanged, white surfaces, pale violet selected states, charcoal text, and semantic green/red movement feedback. The search's marketing showcase pattern and Latin font pairing are not suitable for this internal Persian MVC app; use task navigation and system Persian fonts instead. No external fonts, libraries, or image services are required.

Brand: primary #492783, strong #35195f, soft #f0eaf8, background #f6f7fb, text #222639, secondary text #626779, border #e3e5ed. Keep logos proportional. Public assets are selected nonempty files copied from docs/kimia-logos/purple; originals remain untouched.

Components: 44px minimum buttons, 48px inputs, 10px control radius, 16px cards, 20–24px spacing. Right sidebar becomes wrapping navigation on tablet/mobile. Respect reduced motion, keyboard focus, input autocomplete and visible labels. Use Bootstrap RTL. Dashboard uses real identity/permission information rather than fabricated inventory statistics.

Validation limitation: SDK 10.0.302 required by global.json is unavailable locally. Build and runtime browser validation require that SDK. Do not change the project's SDK contract solely for styling.
